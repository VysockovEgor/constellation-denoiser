# E047 — Фаза 3: каскад триплетных ступеней, варианты обучения

**Вопрос.** Что меняют у малого каскада (2 ступени, M = 4, K_th = 16, КИХ7; 1 136 RM) общие C, пошаговое обучение, ридж-инициализация и отказ от симметрий?

**Правило (до запуска, черновик).** Вариант отличается от эталона v1, если |разность средних теста| > 2 std по 5 seeds; знак — как измерен. Полностью — `config.json` → `rule_draft`.

**Варианты** (по одному фактору): v1 — независимые C, совместно (как E040); v2 — общие C; v3 — сначала ступень 1, потом ступень 2 при замороженной первой; v4 — ступень 1 из ридж-решения (проекция на симметричную форму); v5 — свободные коэффициенты без симметрий. 5 seeds × 200k, lr cosine 1e-3. Сетка по числу ступеней и M — в E040 (идёт).

**Команда.** `bash experiments/E047_cascade_variants/run.sh <стадия>`; стадии: control | init | main | all | summarize | smoke.

**Результаты.** `results/variants_summary.csv`, `variants_verdicts.csv`; рисунок `figures/E047_cascade_variants.png`.
