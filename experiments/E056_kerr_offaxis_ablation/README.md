# E056 — абляция: за счёт чего Керр с памятью + внеосевые триплеты лучше, чем только триплеты

## Шаг 0 — по коду
- **(a) Вариант «только триплеты» (T).** Это `e046_fit.job_terms("T")` = `triplet_terms(M, "T3")` + КИХ7 ([triplets.py:21-30](../../src/constellation_denoiser/triplets.py)). В него входят все склеенные члены m ≤ n с |m+n| ≤ M, **включая осевые** (m = 0 или n = 0) и центр (0, 0).
  - Осевой член T_{0,j} = T_{j,0} = x_k·|x_{k+j}|², j = −M…M — это 2M + 1 «керровских» членов.
  - Их коэффициенты свободные и комплексные: не обязаны быть мнимыми и симметричными по j.
- **(b) Керр с памятью.** `kerr_offaxis.Kerr` ([kerr_offaxis.py:53-77](../../src/constellation_denoiser/kerr_offaxis.py)): u = КИХ7(x), y = u·exp(−i Σ_{|j|≤r} α_j |u_{k+j}|²). Веса α вещественные и симметричные (α_j = α_{−j}), отводов N_c = 2r + 1.
  - В первом порядке это ровно осевые члены x_k·|x_{k+j}|² при |j| ≤ r, с чисто мнимыми коэффициентами, симметричными по j.
  - Сверх этого Керр даёт все высшие порядки той же фазы: экспонента сохраняет модуль.
  - Внеосевых членов Керр не содержит.
- **(c) Внеосевые.** `offaxis_terms(M)` — члены T3 с m ≠ 0 и n ≠ 0. **Случай m + n = 0 включён**, например (−1, 1): x_{k−1}·x_{k+1}·x_k*.

## Шаг 1 — ветки при равном RM (уровни ~430, ~1 200, ~2 200; допуск +5 %)

| ветка | состав | откуда |
|---|---|---|
| 1 | все триплеты T3 + КИХ7 | E046 (M 3/5/8), E048 (M 11/15), готово |
| 2 | Керр без памяти (N_c = 1) + внеосевые | **E056, новое** (A1 varpro, M 3–15) |
| 3 | Керр с памятью, без внеосевых | E046 (N_c 7/15/31), E048 (31/63), готово |
| 4 | Керр с памятью + внеосевые (A1) | E046, E048, готово |
| 5 | контроль: Керр без памяти, без внеосевых | **E056, новое** (K, N_c = 1) |

- На каждом уровне берётся лучшая по валидации конфигурация с RM ≤ уровня: M, N_c и набор членов (полный, по модулю, гиперболой).
- Метрика: снижение BER на тесте, mean, std и SE по 5 бутстреп-репликам.
- Ветки 3 и 5 стоят 35–66 RM — на высокие уровни их не поднять, поэтому показаны при своём RM.

## Правило (до запуска, `config.json` → `rule_draft`)
Эффект признаётся, если разность > 2 SE и > 2 std:
- (4) − (2) — память Керра;
- (4) − (3) — внеосевые;
- (2) − (1) — экспоненциальная форма плюс внеосевые против свободных осевых.

Иначе — «не доказано».

## Ограничения
- 5 реплик — это бутстреп обучающих файлов в закрытой форме, а не seed обучения.
- Одно разбиение (E004).
- Конвенция RM — проекта (4 RM на комплексное умножение, прямой счёт).
