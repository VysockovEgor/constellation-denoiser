# E045 — Фаза 1: эталоны на единой шкале RM

**Вопрос.** Как выглядят линейный КИХ, DBP, Керр с памятью (PhysKerr), одношаговые полные триплеты, DBP + триплеты и каскад на одной шкале RM (среднее ± std по seeds)?

**Что делает** (`summarize_E045.py`, без обучения): точки из готовых прогонов — агрегатор v2 (E024) для КИХ, DBP и PhysKerr; закрытая форма E031/E034/E036 (std по 5 бутстреп-репликам); E038; каскад E040 — после его сводки. Для каждого семейства — Парето-точки по валидации. Только конвенция RM репозитория; другие — в E039/E043, в одной таблице не смешиваются. DBP «1 шаг на пролёт» (20 шагов) не запускался: он лежит между точками E028 Ns16 и Ns32.

**Команда.** `PYTHONPATH=src python -m constellation_denoiser.summarize_E045` (локально, секунды).

**Результаты.** `results/references.csv`, `results/references_pareto.csv`; рисунок `figures/E045_references_vs_rm.png`.
