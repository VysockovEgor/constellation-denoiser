# E032 — Сходимость: 1 000 000 шагов для финалистов

**Вопрос.** Меняется ли рейтинг, если обучать до плато (в E011 и E018 плато не достигалось за 200k)?

**Правило (до запуска, черновик).** Плато достигнуто, если выигрыш 500k → 1M меньше 0.3 п.п. (среднее по seeds); ранжирование стабильно, если порядок моделей при 200k и 1M совпадает и разности знака не меняют. Тест на горизонте H — в точке лучшей валидации среди оценок до H (каждые 20k). Полностью — `config.json` → `rule_draft`.

**Модели** (рецепты E025): one_hidden h48 (F2), v4 h119 (F3), both h48 (F4), гибрид h48 (F9), лучший DBP по валидации E028 (иначе Ns8 L31 R7, F6), лучшая вещественная (F10/F11 по валидации E025). Каждая × 3 seeds × 1M шагов.

**Запуск.** Отдельная tmux-сессия `q_conv` с JOBS = 16, стартует после S3 E025 (её запускает очередь `scripts/overnight_e024_e033.sh`).

**Команда.** `bash experiments/E032_convergence_1m/run.sh <стадия>`; стадии: control | main | all | summarize | smoke.

**Результаты.** `results/horizons.csv`, `results/convergence_verdicts.csv`; рисунок `figures/E032_valbest_test_vs_steps.png`.
