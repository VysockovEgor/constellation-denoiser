# E040 — Каскад триплетных ступеней (как PB-DBP) в моих координатах

**Вопрос.** Даёт ли каскад малых триплетных ступеней выигрыш над одношаговыми триплетами (M31, K2048, M51) при равных RM на моих данных?

**Правило (до запуска, черновик).** Каскад лучше одношаговых на уровне RM (6k, 12k, 18k; RM в ±5 %), если тест выше на ≥ max(1.5 п.п., 2 × разброс seeds контроля) и интервалы min–max не пересекаются, на 2 из 3 уровней; иначе не различимы. Если каскад не лучше — для одной поляризации с убранными линейными эффектами многошаговость не нужна, E041 только после решения автора. Полностью — `config.json` → `rule_draft`.

**Модель** (`cascade_e040.Cascade`, вид `cascade`): x_s = FIR_s(x_{s−1} + T_s(x_{s−1})), C_mn = C_nm = C_{−m,−n} = −C*_{−m,n}, |m|, |n| ≤ M, |mn| ≤ K_th; C = 0 и FIR = δ в начале; Adam, MSE, lr cosine_to_zero 1e-3. Вариант с общими C на всех шагах. Схема PB-DBP взята у группы научного руководителя (Optics Continuum 4(12), 2896, 2025); здесь — её воспроизведение на моих данных.

**Сетка.** Ns ∈ {1, 2, 4, 8} × M ∈ {2, 4, 8, 16} × K_th ∈ {M²/4, M²} × L ∈ {1, 7, 15}, RM 1 000–30 000, рецептивное поле ≤ 301; плюс точки с целым K_th, попадающие в окна уровней (в плановой сетке их нет). main: 2 seeds × 20k; confirm: по 2 лучших по валидации на уровень и их двойники с общими C, 5 seeds × 200k.

**Команда.** `bash experiments/E040_triplet_cascade/run.sh <стадия>`; стадии: control | main | confirm | all | summarize | smoke | estimate.

**Результаты.** `results/cascade_summary.csv` (три конвенции RM), `cascade_verdicts.csv`, `../../results/gate_e040.json`; рисунок `figures/E040_cascade_vs_one_step.png`.
