# E041 — Смешанные ступени и распределение RM под бюджет

**Вопрос.** Если тип каждой ступени выбирать отдельно (фазовая Kerr-ступень, триплетная, обе, пропуск) под общий бюджет RM, лучше ли это равномерного каскада E040 при тех же RM?

**Правило (до запуска, черновик).** Смешанные ступени лучше равномерного каскада на уровне (3k, 8k, 16k RM, ±5 %), если тест выше на ≥ max(1.5 п.п., 2 × разброс seeds контроля) и интервалы не пересекаются, на 2 из 3 уровней; иначе кандидат A закрыт. Аналога в проверенных источниках не найдено (уровень проверки — аннотации, `docs/literature_check.md`). Полностью — `config.json` → `rule_draft`.

**Запускается**, только если `results/gate_e040.json` показывает, что каскад лучше одношаговых, или есть `results/gate_e040_decision.json` с `run_e041: true` (решение автора).

**Поиск** (одинаковый бюджет у обоих плеч): по 60 случайных конфигураций на уровень (смешанные: Ns 2–8, тип ∈ {K, T, KT, skip}, R ∈ {1, 3, 7, 15}, M ∈ {2, 4, 8, 16}, K_th ∈ {M²/4, M²}, L ∈ {1, 7, 15}; равномерные: одинаковые T-ступени, M 2–16, любое целое K_th) × 2 seeds × 20k → топ-4 × 3 seeds × 60k → топ-2 × 5 seeds × 200k. Отчёт: карта типов ступеней по позициям для топ-10.

**Команда.** `bash experiments/E041_mixed_stages/run.sh <стадия>`; стадии: control | s1 | s2 | s3 | all | summarize | smoke | estimate.

**Результаты.** `results/mixed_summary.csv`, `mixed_verdicts.csv`, `type_by_position.csv`; рисунки `figures/E041_*.png`.
