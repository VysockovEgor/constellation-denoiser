# E053 — сумма «чирпов» вместо таблицы внеосевых C (H1) и быстрый подсчёт триплетов (H2)

Новизну схемы «Керр + внеосевые IFWM-триплеты» не заявляем (Liang, Kumar 2014; Xiao 2025). Проверяем одно: можно ли таблицу C заменить формулой с малым числом параметров и считать её быстрее.

## Правило (до запуска на данных, `config.json` → `rule_draft`)
- **H1 подтверждена**, если хотя бы при S ≤ 5 чирпах и ≤ 20 вещественных параметрах среднее на test (5 реплик) ниже полной таблицы (i) меньше чем на std(i). Оба правила значимости, 2 SE и 2 std, указываются.
- **H1 отвергнута**, если при S = 8 все чирповые варианты хуже (i) больше чем на 2 SE и больше чем на 2 std.
- Иначе — **не доказано**.
- Чирповая форма «уникальна физически», только если обгоняет радиальный базис (iii) при равном числе параметров по обоим правилам.

Самого алгоритма в статье нет: это допущение о потенциале.

**Разд. 3.3.3, с. 2904: повторно используемые произведения.** Нелинейный шаг записан как w[k] = v[k] + Σ C_mn v[k+m](v[k+n]v*[k+m+n] + …), с отсевом |mn| ≤ K_th и тремя симметриями C.
- Цена в комплексных умножениях: центральный член — 4, осевые и диагональные — 13, остальные — 25 на член (две поляризации).
- Наборы индексов соседних отсчётов I_k и I_{k+1} в основном совпадают. Поэтому «двойные произведения» v[k+n]v*[k+m+n] с отсчёта k переносятся на k+1; их число R задаёт формула (12), итоговая цена — формула (13).

**Что берём себе (одна поляризация, моя адаптация):** двойное произведение y_m[a] = x_a·x*_{a+m} считается один раз на символ на каждый лаг m. Тогда член стоит 2 комплексных умножения (8 RM), плюс 4 RM на новое двойное произведение. Если ещё сгруппировать по m, выходит 4 RM на член (колонки (2) и (2b) в `results/rm_vs_M.csv`). Рекурсия H2 идёт дальше: для чирпа число операций на символ растёт как O(M), а не O(M²).

## Проверки алгебры (случайные комплексные данные; `chirp_triplets.check`, `results/recurrence_check.csv`)
- **Тождество размыкания** x~_a = x_a·e^{−i(a−o)²/(2η)}. Алгебра: (p+m)² + (p+n)² − (p+m+n)² = p² − 2mn. Относительная ошибка 2·10⁻¹⁶ … 5·10⁻¹⁴ для любого начала отсчёта o: блоки могут начинаться заново, фаза не растёт.
- **Квадрант A, рекуррентность** S_p[k] = 2x~_p x~_{p+k} + S_{p+1}[k−2]: верна. При |m+n| ≤ M (домен A1) получается просто K = M, ограничение рекурсии не мешает. В квадрате (|m|,|n| ≤ M) нужен усечённый S, он посчитан прямо.
- **Квадрант B (идея из задания): верна.** Пары с фиксированной суммой позиций c = 2p + e, вес T(d), d = m − n. Сумма по d берётся префиксными суммами, то есть только сложениями; |e| ≤ M − 1. Совпадает с прямым счётом с ошибкой ≤ 5·10⁻¹⁴ в T3 и в квадрате.

## H2 против формулы Xiao для внеосевой части шага

Формула Xiao 2025: K·(2·C_conv(N_f) + 12) RM на символ — из литературы, по пересказу задания. Она дана для креста min(|m|,|n|) ≤ K, max(|m|,|n|) ≤ L при **произвольных** коэффициентах вдоль линий креста, то есть внеосевые члены там уже считаются быстро, свёртками через БПФ. Что значит N_f, в тексте не определено; посчитано при N_f = 2M + 1 и при N_f = M + 1, вывод от этого не меняется (`results/rm_vs_M.csv`).

**Вывод (арифметика; формула Xiao не проверена в коде):**
- **H2 как новизна отпадает.** Быстрый подсчёт внеосевых триплетов есть у Xiao. Он работает при произвольных коэффициентах и стоит O(K·log N_f) на символ.
- **При малых K (1–3; у Xiao это оптимум)** их схема дешевле любой нашей с S ≥ 1 в 1.2–15 раз.
- **На всём домене (K = M)** один наш чирп дешевле в 2.1–2.7 раза. Но уже S = 3 чирпа дороже Xiao, а выигрыш требует, чтобы подтвердилась H1 — данные с этим пока не согласны (1a).
- **Что остаётся от рекурсии:** прямой счёт без БПФ, то есть потоковый, с малой задержкой, и для одного чирпа дешевле. Это инженерная деталь, а не новизна.
- **Оговорка.** Домены разные: у Xiao крест в квадрате, у нас T3. Внутреннее устройство алгоритма Xiao я не видел — только формулу цены.

## 1a — подгонка таблиц C (сохранённые ридж-таблицы, реплика r17, средняя λ; `results/table_fit.csv`)
- **Ошибка подгонки.** Полностью свободная форма: S = 1 — −9.2 / −8.3 / −7.3 дБ (A1 M8, M11, M15); S = 8 — −25.8 / −22.4 / −17.6 дБ. Разброс между репликами самой таблицы (пол шума) — −28…−31 дБ, то есть у таблицы есть структура, которую 8 чирпов не ловят. Хуже всего воспроизводятся большие |m|,|n|.
- **Свободные A_s почти чисто мнимые** (фаза ±90–95°): симметрия C(m,n) = −C*(−m,n) у ридж-решения выполняется. Режим A_s = i·a_s почти не уступает комплексному (при S = 8 он на 0–3 дБ хуже: −23.0 против −25.8 у M8).
- **η.** Найденные |η| ≈ 3–27, в основном отрицательные, — в диапазоне физической справки |β₂|·z·Rs² = 0…43 (для z ≤ 2000 км; из литературы, не из генератора), что не противоречит идее квадратуры по z. Но |η| первого чирпа растёт с M (12.8 → 15.2 → 18.2), так что η зависит от окна.
- **Ширина треугольника** W/(2π|η|) ≈ 0.17–0.5, а не 1 (Xiao). Фиксированные W = 2π|η| или π|η| при малых S хуже свободного W на 3–4 дБ.
