# E037 — Триплеты на других разбиениях файлов

**Вопрос.** Обходят ли триплеты нейросети на каждом разбиении файлов, и устойчив ли их результат?

**Правило (до запуска, черновик).** T3 + КИХ7 при M = 21 лучше лучшей сети E023 (по валидации) на каждом разбиении — минимум триплетов выше максимума сети; разброс средних триплетов между разбиениями < 2 п.п. Полностью — `config.json` → `rule_draft`.

**Что делает.** Три разбиения E023 (`grids.e023_split`, seeds 101, 202, 303: те же 300 файлов, train 30, validation 45, test 45); на каждом — закрытая форма T3 + КИХ7 при M ∈ {15, 21, 25}, 5 бутстреп-реплик. Сети — из `E023…/results/runs_table.csv` (5 seeds, 100k).

**Команда.** `bash experiments/E037_triplets_splits/run.sh <стадия>`; стадии: main | fit | summarize | smoke. CPU, минуты.

**Результаты.** `results/split_summary.csv`, `networks_by_split.csv`, `split_verdicts.csv`; рисунок `figures/E037_triplets_by_split.png`.
