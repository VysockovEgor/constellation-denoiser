# E031 — Физическая лестница: триплеты теории возмущений

**Вопрос.** Чего не хватает фазовой модели PhysKerr (9 %), и как стоит классический метод возмущений при равных RM?

**Правило (до запуска, черновик).** Диагональной (XPM) физики недостаточно, если T3 − T2 ≥ 5 п.п. при равном M; T1 ≈ PhysKerr, если |T1 − 9.3| < 3 п.п.; наш подход лучше PB-NLC при равных RM, если разница Q² ≥ 0.1 дБ и интервалы не пересекаются (проверка в E033). Полностью — `config.json` → `rule_draft`.

**Модель** (`triplets.py`; вид по Tao и соавт., JLT 2011 — по PDF не сверялось): y_k = x_k + Σ C_{m,n} x_{k+m} x*_{k+m+n} x_{k+n}, |m|, |n|, |m+n| ≤ M; члены (m, n) и (n, m) совпадают и объединены. Руки: T1 (XPM, m = 0 или n = 0, C чисто мнимые), T2 (XPM, комплексные C), T3 (все), T3 + КИХ L ∈ {7, 15}; M ∈ {3, 5, 7, 11, 15, 21}. МНК с ридж-регуляризацией, λ по валидации; нормальные уравнения накапливаются по файлам блоками по 4096 символов. RM: `naive` (12 на упорядоченный триплет) и `sym` (12 на объединённый член), плюс 4L у КИХ. «Seeds» — 5 бутстреп-реплик файлов обучения (17 … 71).

**Контроль.** Юнит-тест: МНК восстанавливает заданные C на синтетике (`tests/test_e024_e033.py`); нулевые C дают сырой BER. Обучения по шагам нет, поэтому контроль complex_a здесь не запускается.

**Команда.** `bash experiments/E031_perturbation_triplets/run.sh <стадия>`; стадии: main (fit + summarize) | fit | summarize | smoke. CPU, минуты.

**Результаты.** `results/triplet_fits.csv`, `triplet_summary.csv`, `triplet_verdicts.csv`, `runs_table.csv`; рисунок `figures/E031_triplets_vs_rm.png`.
