# E003 — Большой пилот и аудит данных

## Вопрос
Провести большой пилот на уникальных файлах и зафиксировать аудит набора данных.

## Правило интерпретации (до запуска)
`unknown`: сохранённая конфигурация не включает предварительный критерий.

## Протокол
- Данные: 1 356 уникальных файлов; выборка 300 файлов, split 210/45/45,
  split seed 20261003.
- Seed моделей: 17, 29, 43.
- Команда из legacy summary:
  `PYTHONPATH=src python -m constellation_denoiser.large_scale_pilot --sample-files 300 --seeds 17 29 43 --epochs 40 --patience 10 --batch-size 1024 --threads 6`.
- Данные аудита и split-метаданные находятся в `data/manifest/` и `results/`.

## Результат
Таблицы и bootstrap JSON находятся в `results/`; график —
`figures/E003_large_scale_pilot.png`. `large_scale_pilot_summary.csv` содержит
complex seed 29 test BER 0.003528529 и raw test BER 0.009551860.

## Вывод
Не добавлялся новый вывод сверх приведённых чисел и исходных таблиц.

## Ограничения
Пилот использует выборку 300 из 1 356 уникальных файлов и три seed.
Сохранённые результаты не изменялись при миграции.
