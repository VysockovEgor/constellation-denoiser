# E043 — Сводка и честное сравнение триплетных семейств

**Вопрос.** Как выглядят одношаговые триплеты, каскад E040, смешанные ступени E041, Kerr-сети и DBP на одной картине «ΔQ² и снижение BER против RM», и меняется ли картина при другой конвенции подсчёта RM?

**Что делает** (`summarize_E043.py`, без обучения): точки семейств из сводок E031/E034/E036, E040 (confirm), E041 (S3) и агрегатора E033 (Kerr MLP, DBP; агрегатор v2 из E024 уже исправлен); три оси RM (репозиторий; буферная схема для одной поляризации — моя оценка; формула arXiv 2409.20023; у сетей и DBP оси совпадают); таблица лучших по валидации на уровнях 3k, 8k, 16k, 25k RM (окно ±25 % в лог-шкале).

**Что не доказано.** Потолок снижения BER (нет эталона линейного режима); источник данных и мощность запуска; одна поляризация, одна линия, одна мощность; конвенция подсчёта RM группы не сверена с формулами (10)–(13) их статьи; полнота литературной проверки (только аннотации, платные и русскоязычные журналы не покрыты).

**Команда.** `bash experiments/E043_triplet_summary/run.sh <стадия>`; стадии: main | smoke.

**Результаты.** `results/points.csv`, `level_best.csv`, `level_best.md`; рисунок `figures/E043_pareto_three_rm.png`.
