# E054 — DBP-X с обучаемыми КИХ: физический старт 255, прогрессивная обрезка до 31 / 15 / 7

## Вопрос
Какую часть снижения BER сохраняет DBP-X, если во время обучения КИХ шага укорачивать с 255 отводов до 127, 63, 31, 15 и 7? Какой RM при каждой длине — по обеим конвенциям? Основной эталон — Ns = 20 (10 seed); Ns = 40 — дополнительно (5 seed).

## Правило (до запуска, `config.json` → `rule_draft`)
- Для каждого (Ns, L): mean, std, SE и размах по seed, доля уровня L = 255, RM в обеих конвенциях.
- Прогрессивная обрезка лучше резкой при данной длине, если разница > 2 SE и > 2 std (по 5 seed).

## Схема
- **Старт** — физические отводы шага при L = 255. Ядро α, g, знак и множитель c взяты из E050 `start` (выбор по валидации).
- **Обучение.** Adam 1e-3, по 4 файла целиком за итерацию. 3 000 итераций при 255 отводах, затем на каждую следующую длину:
  - **прогрессивная** обрезка — 1 000 итераций плавного сужения маски, затем 2 000 дообучения;
  - **резкая** (контроль) — отрезать сразу, затем 3 000 итераций.
- **На каждой длине** берётся чекпоинт с минимальным MSE на валидации, на нём — test.
- **Мотивация.** E050 `unittest`: без обучения обрезка физических отводов до 31 даёт −107…−574 %.

## RM
Обе колонки основные: прямая свёртка (конвенция проекта) и БПФ / overlap-save (Xiao); у D_total 401 отвод. Выбор конвенции ждёт ответа научного руководителя.
