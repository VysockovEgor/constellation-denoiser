# E015 — Диагностика физики на данных (без обучения)

## Вопрос
Зависит ли фазовая ошибка принятого символа от мощности соседей, а не только от
его собственной мощности? Это проверка исходной гипотезы E016–E018 без
нейросети; счёт — минуты.

## Правило интерпретации (до запуска) — ЧЕРНОВИК
Статус: черновик, пользователь подтверждает его до первого запуска; после
просмотра результатов не меняется. Копия в `config.json` → `rule_draft`.

«**Память есть**», если одновременно:
- (а) на валидации |ρ(dphi, P_nb(R))| ≥ |ρ(dphi, |z|²)| хотя бы для одного
  R ∈ {1, 3, 7, 15} (Спирмен по всем окружностям);
- (б) на валидации подгонка с R = 7 снижает BER не менее чем на 2 п.п.
  сильнее, чем подгонка с R = 1;
- (в) на тесте совпадают знак и порядок величины: тот же знак и отношение
  тест/валидация в пределах [0.1, 10]. Проверяется для ρ того R, у которого
  наибольший |ρ| на валидации, и для разрыва R7 − R1.

Иначе — «не доказано». Для каждого числа приводится 95 % интервал бутстрапа по
файлам (200 повторов). Seeds в E015 не определены: обучения нет.

## Данные и нормировка
- `data/README.md` и сами CSV: в строке `tx_I, tx_Q, rx_I, rx_Q` — один
  отсчёт на символ, **одна поляризация**, 16 384 символа в файле. Принятые
  символы уже после компенсации линейных эффектов и восстановления фазы: это
  тот же «сырой» сигнал, по которому считается raw BER во всех экспериментах.
- Созвездие нормировано: уровни ±1/√10, ±3/√10 (`core.LEVELS`), средняя
  мощность 1 (`tx_rms` ≈ 0.9986 в аудите). Окружности |a| = 0.447, 1.000, 1.342.
- Символы — центральные для окна 31 (по 15 отрезаются у краёв файла), как в
  метрике BER E010–E014. Train — 30 файлов (только для подгонки α), validation —
  45 (решения), test — 45 (отчёт); split E007–E014.

## Что считается
1. `dphi_k = angle(z_k · conj(a_k))` ∈ (−π, π].
2. Средние и стандартные отклонения `dphi` в 20 квантильных бинах собственной
   мощности |z_k|² и мощности соседей `P_nb(R) = Σ_{0<|j|≤R} |z_{k+j}|²` для
   R ∈ {1, 3, 7, 15}; карта 10×10 (собственная мощность × P_nb(7)).
3. Спирмен ρ(dphi, |z|²) и ρ(dphi, P_nb(R)) — по всем символам и отдельно для
   внутренней, средней и внешней окружности (по переданному символу).
4. Остаточная MSE сырого сигнала |z − a|² против P_nb(R). Чекпоинтов E014
   `k0_kerr` локально нет (их не забирали с сервера), поэтому остаток модели
   не считается — только сырой сигнал. Обучение ради этого не запускается.
5. Прямая подгонка формулы без нейросети:
   `min_α Σ |z_k·exp(−i Σ_j α_j |z_{k+j}|²) − a_k|²`, j = −(R−1)/2 … (R−1)/2,
   R ∈ {1, 3, 7, 15, 31} коэффициентов. Используется `scipy.optimize` (L-BFGS-B),
   градиент через torch в float64, старт α = 0, только train. На validation и
   test считаются снижение BER и `q2_gain_db`; α сохраняется в
   `results/alpha_fit_R{R}.csv`.

Бутстрап: файлы выбираются с возвращением (seed 20261023), интервалы —
перцентильные 2.5–97.5 %. Для подгонки α фиксированы, бутстрап идёт по файлам
оценочной выборки. Спирмен считается по рангам всей выборки; в бутстрапе
переиспользуются эти ранги через пофайловые суммы. Ранги внутри каждой
выборки не пересчитываются — это приближение, принятое ради скорости.

**Контроль.** Нейросеть не обучается, поэтому контроль `complex_a` из ЧАСТИ 0
здесь неприменим. Вместо него проверяется конвейер данных: raw BER теста
должен совпасть с 0.009551859551859552
(`experiments/E004_training_file_curve/config.json`) с точностью 1e-12. Иначе
пишется `ОШИБКА`, остальные расчёты не выполняются.

Q² (дБ): `10·log10(10·erfcinv(8·BER/3)²)` (`src/constellation_denoiser/q2.py`).
Формула взята из промпта как уравнение (17) статьи Sidelnikov et al., JLT 2021.
PDF этой статьи в `references/source_papers/` нет, там только
`Bogdanov_341.pdf`, поэтому сверить формулу не удалось.

## Ограничения
- Подгонка меняет только фазу. Остаточные амплитудные искажения и межсимвольную
  интерференцию формула не трогает, поэтому её выигрыш по BER — нижняя оценка
  того, что даёт память.
- Корреляция фазовой ошибки с мощностью не равна причинности: на неё влияют
  шум и решения на границах.
- Приближённый бутстрап Спирмена (см. выше); один split.

`LOG.md`. По результатам E015 в E018 допустимо заменить R (см. его README).
