# E061 — Триплеты T3 + КИХ7 (M = 15): связывание коэффициентов и отброс членов с пересчётом

**Вопрос.** Насколько можно удешевить триплетную модель (368 членов: 31 осевой, 337 внеосевых) без потери качества? Рассматриваются зеркальная связь C(m, n)–C(−n, −m), общий коэффициент g(m·n) и отброс внеосевых членов с ридж-пересчётом. Как эти варианты соотносятся с ветками абляции E056 и с DBP-X на одной оси RM?

**Правило (до запуска, черновик).** λ и K выбираются только по валидации, test считается один раз в конце.
- «Без потери» — валидация ≥ T0 − 0.5 п.п.
- g(m·n) «помогает», если T2 укладывается в этот допуск при меньшем RM_b.
- Разница на test считается реальной, если она > 2 SE парной пофайловой разности.
- «Сопоставимо с DBP-X при 1.4k RM» — RM_b ≤ 1400 и test ≥ 94.07 %.

Полностью — `config.json` → `rule_draft`.

**Варианты.**

| вариант | что делается |
|---|---|
| T0 | свободные коэффициенты |
| T1 | зеркальная связь: равенство или сопряжение, по измерению на T0 |
| T2 | общий g(p) на каждое p = m·n со знаком |
| T2c | корзины \|p\| |
| T4 | отброс по \|C\| из T0 |
| T5 | отброс по \|m·n\| и по max(\|m\|, \|n\|) |
| T6 | лучшая связь + лучший отброс |

- Осевые члены и КИХ7 остаются всегда.
- K — число оставленных **внеосевых** членов: 8 … 337.
- T3 (физическая форма) пропущен, причина — в `config.json`.

**Цена.**
- (a) наивно: 12 RM на член + 28.
- (b) с общими коэффициентами: 8 RM на член + 4 RM на независимый коэффициент + 28.
- На рисунке у триплетов (b), у DBP-X — БПФ-подсчёт, у веток E056 — конвенция проекта (= a).

**Контроль.** Обучения нет, поэтому `complex_a` не запускается. Вместо него T0 должен воспроизвести валидацию E060 (67.884 %) с точностью ±0.05 п.п.

**Команда.** `bash experiments/E061_triplet_optimization/run.sh <стадия>`; стадии: main | plot | smoke.

**Результаты.** `results/results.csv`, `symmetry.json`, `verdicts.json`, `control.json`; рисунок `figures/E061_triplet_optimization.png`.

## Результат (2026-11-09, сессия E061_1109_1906)

Контроль пройден: T0 на валидации 67.884 % = E060 (`results/control.json`).

**Проверка симметрий на T0** (`results/symmetry.json`):
- Зеркальная связь C(m, n)/C(−n, −m), 176 пар. Модуль: ||ρ| − 1| — медиана 0.032, 90-й процентиль 0.122. Фаза: |arg ρ| — медиана 0.032 рад, 90-й процентиль 0.133 рад. При сопряжении |arg| — медиана 1.25 рад. Значит, связь — **равенство**.
- Группы по p = m·n: 128 групп, из них 117 с ≥ 2 членами. Разброс внутри групп — 9.1 % от |C| (среднеквадратично, по всем группам), медиана по группам 5.1 %. При случайной группировке тех же размеров разброс 78 %.

Вывод по правилу:
- Без потерь (в пределах 0.5 п.п. по валидации) удешевляет только связывание. Лучшее — T2: RM (b) 4 444 → 3 608, это −19 %; разница на test −0.02 п.п. при SE 0.10. g(m·n) «помогает» по правилу.
- Отброс с пересчётом на сетке K без потерь не проходит: при K = 256 валидация теряет уже 1.0 п.п.
- Цена 1.4k RM при качестве DBP-X недостижима. Лучшая точка с RM (b) ≤ 1 400 — T6, K = 96: 56.2 % при 1 308 RM. Для сравнения A1 из E056 даёт 60.4 % при 1 242 RM, DBP-X без обучения — 94.9 % при 894 RM.

Ограничения:
- Один набор коэффициентов на вариант, без реплик.
- Сетка K грубая: между 256 и 337 точек нет.
- Сборка триплетов (8 RM на член) не сокращается. Буферная схема E039 не применялась.
- T3 (физическая форма) пропущен.
