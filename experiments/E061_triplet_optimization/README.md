# E061 — Триплеты T3 + КИХ7 (M = 15): связывание коэффициентов и отброс членов с пересчётом

**Вопрос.** Насколько можно удешевить триплетную модель (368 членов: 31 осевой, 337 внеосевых) без потери качества? Рассматриваются зеркальная связь C(m, n)–C(−n, −m), общий коэффициент g(m·n) и отброс внеосевых членов с ридж-пересчётом. Как эти варианты соотносятся с ветками абляции E056 и с DBP-X на одной оси RM?

**Правило (до запуска, черновик).** λ и K выбираются только по валидации, test считается один раз в конце.
- «Без потери» — валидация ≥ T0 − 0.5 п.п.
- g(m·n) «помогает», если T2 укладывается в этот допуск при меньшем RM_b.
- Разница на test считается реальной, если она > 2 SE парной пофайловой разности.
- «Сопоставимо с DBP-X при 1.4k RM» — RM_b ≤ 1400 и test ≥ 94.07 %.

Полностью — `config.json` → `rule_draft`.

**Варианты.**

| вариант | что делается |
|---|---|
| T0 | свободные коэффициенты |
| T1 | зеркальная связь: равенство или сопряжение, по измерению на T0 |
| T2 | общий g(p) на каждое p = m·n со знаком |
| T2c | корзины \|p\| |
| T4 | отброс по \|C\| из T0 |
| T5 | отброс по \|m·n\| и по max(\|m\|, \|n\|) |
| T6 | лучшая связь + лучший отброс |

- Осевые члены и КИХ7 остаются всегда.
- K — число оставленных **внеосевых** членов: 8 … 337.
- T3 (физическая форма) пропущен, причина — в `config.json`.

**Цена.**
- (a) наивно: 12 RM на член + 28.
- (b) с общими коэффициентами: 8 RM на член + 4 RM на независимый коэффициент + 28.
- На рисунке у триплетов (b), у DBP-X — БПФ-подсчёт, у веток E056 — конвенция проекта (= a).

**Контроль.** Обучения нет, поэтому `complex_a` не запускается. Вместо него T0 должен воспроизвести валидацию E060 (67.884 %) с точностью ±0.05 п.п.
