# E011 — Длинные прогоны и сходимость

## Вопрос
Выходят ли модели на плато при 100k+ шагов, каков предел точности и как быстро
они сходятся? В E006 длинные прогоны были только для N=7 и N=210 при seed 17,
покрытие seeds неполное, а на графике seeds и N не различались.

## Правило интерпретации (до запуска) — ЧЕРНОВИК
Статус: черновик, пользователь подтверждает его до первого запуска; после
просмотра результатов не меняется. Копия в `config.json` → `rule_draft`.

- **Плато:** прирост сглаженного (окно 10k, то есть 3 точки при замере каждые
  5k) валидационного снижения BER за последние 50k шагов меньше 0.2 п.п.
- Если плато не достигнуто, пишется «плато не достигнуто за N шагов», а
  `y_inf` приводится только как грубая оценка.
- Разрыв между N=30 и N=210 на длинном горизонте трактуется как
  **переобучение** только если валидационная кривая при N=30 падает
  (сглаженный максимум минус сглаженное финальное значение > 0.2 п.п.), а при
  N=210 нет.

Все оценки делаются по валидации; тест только для отчёта.

## Протокол
| модель | класс | умножений на символ |
|---|---|---|
| `complex_both` | `PaperComplexMLP`, окно 31, hidden 48, Керр на обоих слоях | 16 032 |
| `complex_a` | `AblationComplexMLP` вариант a, Керр только после 2-го слоя | 15 696 (6 480 после слияния) |
| `complex_one_hidden` | `AblationComplexMLP` вариант d, один скрытый слой 48 с Керром | 6 480 |
| `real_tanh` | `WindowMLP` tanh, Xavier normal, MSE, hidden 96 × 2 слоя | 15 360 |

Реальная сеть: в `paper_real_mlp.py` по умолчанию hidden 64. По условию «то же
число умножений, вдвое больше нейронов, два выхода» взят hidden 96 = 2·48:
2W·h + h² + 2h = 15 360, ровно плотная часть `complex_both` (без 7 умножений
на нейрон Керра). Конфигурация зафиксирована в `config.json`.

- N train-файлов ∈ {30, 210}: N=30 — `train_pool_files[:30]` (split E007–E009),
  N=210 — весь пул из `experiments/E004_training_file_curve/config.json`; как
  множество он совпадает с `train_files` E003 (проверено). Validation и test —
  по 45 файлов, те же, что в E003–E009.
- Seeds 17, 29, 43; до `MAX_STEPS` шагов (по умолчанию 200 000); batch 1024;
  Adam. Валидация и тест каждые 5 000 шагов; чекпоинт каждые 10 000 шагов,
  прерванный прогон продолжается с последнего чекпоинта.
- Ветки lr: `const_1e-3` (контроль) и `best_e010` — лучшая конфигурация stage1
  из `experiments/E010_lr_schedule_study/results/stage1_selection.json`,
  горизонт затухания = `MAX_STEPS`. Соответствие: `complex_both` ← `both`,
  `complex_a` и `complex_one_hidden` ← `a` (после слияния `a` эквивалентна
  одному скрытому слою). Для `real_tanh` в E010 нет данных, поэтому ветка
  `best_e010` для неё не строится. Если файла E010 нет, стадия `best`
  пропускается без ошибки.

## Метрики
Кривые валидационного и тестового снижения BER против шагов; финальное
значение и лучшее по валидации (с тестом в этой точке); `t98` — первый шаг, на
котором валидация достигает 98 % финального значения; `y_inf` — подгонка
`y = y_inf − a·steps^(−b)` (a ≥ 0, scipy `curve_fit`) к валидационной кривой с
10k шагов. Если подгонка не сошлась, пишется `NaN`.

## Стадии и число прогонов
| стадия | что | прогонов | шагов на прогон |
|---|---|---|---|
| `control` | `complex_both` и `complex_a`, const 1e-3, N=30, seeds 17, 29, замер каждые 1000 | 4 | 20 000 |
| `const` | 4 модели × N {30, 210} × 3 seeds | 24 | `MAX_STEPS` |
| `best` | 3 комплексные модели × N {30, 210} × 3 seeds (если есть выбор E010) | 18 | `MAX_STEPS` |

Контроль: `complex_both` 61.727 ± 0.7 п.п.
(`experiments/E007_window_width_sweep/results/complex_mlp_sweep_summary.csv`) и
`complex_a` 62.191 ± 0.7 п.п.
(`experiments/E009_kerr_ablation/results/complex_mlp_ablation_summary.csv`) по
среднему seeds 17 и 29 (тест в точке лучшей валидации среди шагов, кратных
1000). Если контроль не прошёл допуск, стадии `const` и `best` не запускаются.

## Команды (из корня репозитория)
```bash
bash experiments/E011_long_runs_convergence/run.sh probe

bash experiments/E011_long_runs_convergence/run.sh control
bash experiments/E011_long_runs_convergence/run.sh const

bash experiments/E011_long_runs_convergence/run.sh summarize
SMOKE=1 bash experiments/E011_long_runs_convergence/run.sh smoke
```
Переменные: `MAX_STEPS` (по умолчанию 200000), `SEEDS`, `JOBS`, `THREADS`,
`DEVICE`, `FORCE`.

## Оценка времени
Печатает `run.sh plan all` на сервере. Это самый долгий эксперимент: около
8.4 млн шагов при полной сетке. Локальный smoke даёт только порядок величины
(≈12 мс на шаг комплексной MLP на одном потоке этой машины) и на сервер не переносится.

## Ограничения
- Один split; 3 seed; validation/test по 45 файлов.
- `y_inf` экстраполирует степенной закон и при отсутствии плато — только грубая оценка.
- При N=30 и 200k шагах каждый train-файл просматривается сотни раз; это
  намеренная проверка переобучения, а не ошибка протокола.
