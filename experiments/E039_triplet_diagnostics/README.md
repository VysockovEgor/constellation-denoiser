# E039 — Диагностика триплетов без обучения

**Вопрос.** Что можно узнать о триплетах из уже полученных результатов и подсчётов (определения E038 и K2048, конвенции RM, структура матрицы C, сырой BER), прежде чем тратить часы сервера?

**Правило (до запуска, черновик).** Структура эксплуатируема, если подстановка параметрической формы C_mn ≈ g(u = mn, v = (m − n)²) с ≤ 5 % свободных вещественных параметров сохраняет ≥ 95 % выигрыша свободных коэффициентов (выигрыш — снижение BER в п.п. над M0 = только КИХ7), при M = 31 по валидации (тест — для отчёта); иначе E042 закрыт. Полностью — `config.json` → `rule_draft`.

**Что делает** (`e039_diagnostics.py`): определения E038 и K2048 из config и сводок; три подсчёта RM на каждую триплетную модель (`rm_group_convention.py`: репозиторий; буферная схема для одной поляризации — моя оценка; формула arXiv 2409.20023); коэффициенты M = 15, 21 из тёплых стартов E035, M = 31, 51 — закрытая форма здесь; сингулярные числа, подгонки полиномами степени 2–4 и сеткой 5 × 5 гауссиан, BER подстановки без дообучения; карты |C| в дБ; сырой BER и таблица пересчёта в ΔQ².

**Команда.** `bash experiments/E039_triplet_diagnostics/run.sh <стадия>`; стадии: main | smoke. Локально, без сервера (закрытая форма, CPU).

**Результаты.** `results/definitions.csv`, `rm_conventions.csv`, `structure_parametric.csv`, `structure_svd.csv`, `structure_verdict.json`, `raw_ber.json`, `q2_table.csv`, `coef_M*.csv`; рисунки `figures/E039_coef_map_M*.png`; `../../results/gate_e039.json`.
