# E023 — Устойчивость к смене разбиения

**Вопрос.** Не зависит ли вывод (порядок семейств и разницы) от одного разбиения train / validation / test?

**Правило (до запуска, черновик).** Вывод устойчив, если порядок участников и знак каждой попарной разницы совпадают во всех трёх разбиениях, а разброс средних между разбиениями у каждого участника < 2 п.п. Полностью — `config.json` → `rule_draft`.

**Условия передачи.** Метаданных в файлах нет (только `tx_I, tx_Q, rx_I, rx_Q` и номер последовательности; raw BER по 300 файлам 0.0074 … 0.0122), поэтому часть «обучение на одном условии, тест на другом» пропущена.

**Протокол.** Те же 300 файлов, перемешанные с seed разбиения 101 / 202 / 303 (test 45, validation 45, train 30); участники — лучшие по валидации конфигурации семейств из E021 (≤ 40k умножений, иначе запасной список), 5 seeds, 100k шагов.

**Команда.** `bash experiments/E023_split_robustness/run.sh <стадия>`; стадии: probe | plan | estimate | list | control | main | summarize | smoke.

**Результаты.** `results/split_summary.csv`, `results/robustness_verdicts.csv`, `figures/E023_split_robustness.png`, `results/members.json`.
