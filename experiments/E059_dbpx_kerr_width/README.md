# E059 — обученный DBP-X: ширина окна Керра R = 1, 3, 7, 15 при Ns = 8 и 20

## Вопрос
Сколько снижения BER даёт обученному DBP-X память нелинейной фазы (окно Керра R = 3, 7, 15) по сравнению с мгновенным Керром (R = 1) при Ns = 8 и 20, и какой ценой?

## Что запускается
- Функция `dbpx.train_one` используется без изменений ([e059_kerr_width.py](../../src/constellation_denoiser/e059_kerr_width.py)).
- Модель: точный фиксированный D_total, затем Ns × [симметричный КИХ L = 255, фаза Керра с симметричными α по R соседям], затем комплексное усиление.
- Старт:
  - физические отводы;
  - α = g·δ/(Ns·P) — классическое ядро, одинаковое при всех R, так что память появляется только при обучении;
  - знак, множитель и g — по выбору E050 start на валидации: Ns 8 — +1, 0.85, 0.16; Ns 20 — +1, 1.05, 0.38.
- Обучение в два этапа, как в лучшей ветке E050:
  1. L_D (Xiao): 3 000 итераций Adam 1e-3, сохраняется наименьший L_D;
  2. MSE: Adam 1e-4, 5 000 итераций, 4 целых train-файла со случайным циклическим сдвигом.
- Чекпоинт — минимум MSE на валидации. Веса сохраняются (`.pt`, не коммитятся).
- Seeds: 17, 29, 43, 57, 71. Контроль `complex_a` — как в E054.
- Проверка воспроизводимости: Ns 20, R 7 повторяет ветку E050 «classical, two» (99.249 %, 10 seeds).

## Правило (до запуска, `config.json` → `rule_draft`)
- **Память помогает** при данном Ns, если test(R) − test(1) > 2 SE и > 2 std; иначе — «не доказано».
- **Достаточное R** — наименьшее R, среднее которого не дальше max(2 SE, 2 std) от лучшего R.

## Ограничения
- Одно расписание; g не подбирается отдельно для каждого R; 5 seeds.
- Файлы циклические; один канал, одна поляризация, 1 отсчёт на символ.
- Цену определяет КИХ из 255 отводов: при прямой свёртке R меняет RM меньше чем на 2 %.
- При Ns = 8 и L = 255 юнит-тест усечения E050 не делался (были только Ns 20 и 40). Память шага при Ns = 8 — около 34 символов, гораздо меньше 255.
- Конвенция RM не меняется (ждём ответа научрука): приведены все колонки.
