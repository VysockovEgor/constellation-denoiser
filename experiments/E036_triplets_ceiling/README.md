# E036 — Потолок триплетов

**Вопрос.** Где останавливается рост качества триплетов T3 + КИХ с памятью M, и сколько членов сохраняют качество большой памяти?

**Правило (до запуска, черновик).** Рост продолжается, если M = 51 − M = 31 (E034) ≥ 1 п.п. (тест, 5 реплик); K = 2048 членов сохраняют ≥ 95 % снижения полной модели M = 51. Полностью — `config.json` → `rule_draft`.

**Что делает.** Та же процедура, что E034 (`summarize_E034.fit`): T3 + КИХ7 при M ∈ {41, 51} и отбор K ∈ {512, 1024, 2048} членов из пула M = 51 (ранжирование |C|·rms на train, λ по валидации). 5 бутстреп-реплик. Пул M = 51 — 3 979 членов.

**Команда.** `bash experiments/E036_triplets_ceiling/run.sh <стадия>`; стадии: main | fit | summarize | smoke. CPU, BLAS 16 потоков.

**Результаты.** `results/triplet_ext_summary.csv`, `triplet_ceiling_verdicts.csv`; рисунок `figures/E036_triplets_ceiling.png`.
