# E052 — DBP-X при малых Ns + внешние внеосевые триплеты (крест, закрытая форма)

## Вопрос
Достигает ли DBP-X с Ns = 8 и внеосевыми триплетами на выходе (крест min(|m|,|n|) ≤ K, K = 1..3) уровня DBP-X с Ns = 40 без триплетов при том же или меньшем RM? Также проверяются Ns = 4, 10, 20.

## Правило (до запуска, `config.json` → `rule_draft`)
Проверяется отдельно в каждой конвенции RM:
- **Достигает** — среднее по 5 репликам у Ns 8 + триплеты ≥ значения Ns 40 при RM ≤ RM(Ns 40).
- **Не хуже** — разрыв меньше 2 std и меньше 2 SE реплик. Ns 40 — одно детерминированное значение без seed.
- Иначе — **не достигает**.

## Модель
- **DBP-X не обучается.** Конфигурация взята из E050 `start` (выбор по валидации): знак, ядро (классическое или ридж-форма), g, множитель c, комплексное усиление. Фильтры точные, циклические.
- **Триплеты.** Домен — квадрат max(|m|,|n|) ≤ M, M ∈ {8, 15}. Коэффициенты подбираются ридж-решением на 30 файлах, 5 бутстреп-реплик; λ — по BER на валидации.
- **Метрика** — как в E050: обрезанная область [512, T − 512).

## RM
Обе колонки основные:
- прямая свёртка — конвенция проекта;
- БПФ / overlap-save — по Xiao.

Выбор конвенции отложен до ответа научного руководителя. Триплеты стоят 12 RM на член в обеих колонках. Открытый вопрос: линейная часть DBP-X в реальном приёмнике заменяет CDC; честно ли относить её стоимость к DBP-X целиком — не решено.

## Очередь
`scripts/overnight_e052.sh` (`remote.sh go e052 all`). Ждёт E050 `start`, затем:
1. E050 `probe-test` — параметры проб на 45 тестовых файлах без нового подбора;
2. сводка E050 с таблицей насыщения по Ns 20/40/80 — потолок эмпирический, не измеренный;
3. контроль, подгонки и сводка E052.
