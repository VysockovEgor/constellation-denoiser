# E051 — строгий A-M эталон Liang–Kumar (одна ступень) против A1 / A3

## Вопрос
Даёт ли строгая A-M форма v = (u + T(u)C)·exp(−iφ(u)) что-нибудь сверх A1 и A3 при том же RM и тех же внеосевых членах? Здесь фаза и внеосевая сумма считаются от одного u, параллельно; u = КИХ7(x). Варианты E046 для сравнения:
- **A1:** сначала Керр, затем триплеты от его выхода;
- **A3:** Керр плюс триплеты от x.

Второй вопрос — какой отсев лучше при фиксированном Керре: крест min(|m|,|n|) ≤ K (Xiao), гипербола |mn| ≤ K_th или по модулю коэффициента.

## Правило (до запуска, `config.json` → `rule_draft`)
- **LK против A1/A3.** LK лучше, если при тех же (M, N_c, набор членов) и том же или меньшем RM средняя разность на test по 5 репликам > 2 SE и > 2 std. На лучшей по валидации конфигурации знак должен совпасть на всех 3 разбиениях E023.
- **Отсев.** Крест лучше гиперболы, если при ближайшем числе членов разность > 2 SE и > 2 std.
- Иначе — «не доказано».

## Модель и подгонка
- **Домен.** Внеосевые члены (m ≤ n, m, n ≠ 0) из квадрата max(|m|,|n|) ≤ M, M ∈ {5, 8}; N_c ∈ {7, 31}. Отсев внутри квадрата: крест K ∈ {1, 2, 3, 5}, гипербола K_th ∈ {1, 2, 4, 8, 16}, по модулю K ∈ {8, 16, 32, 64, 128}.
- **Коэффициенты LK — два способа.**
  - `varpro`: (КИХ, α) по L-BFGS на 4 файлах, C исключается ридж-решением. Точно, потому что |e^{−iφ}| = 1: |v − s|² = |T(u)C·e^{−iφ} − (s − u·e^{−iφ})|².
  - `seq`: сначала один Керр, затем ридж-решение для C.
  - В обоих способах C затем пересчитывается в закрытой форме на 30 файлах; λ выбирается по валидации, 5 бутстреп-реплик.
- **RM.** LK стоит столько же, сколько A1: сначала (u + T·C), затем один поворот.
- **Мнимые осевые коэффициенты.** Проверено в E044: |Re C|/|C| на осях, медиана 1.0–1.6 %. У LK α вещественны по построению.

## Ограничения
- Одна ступень; один канал, одна поляризация, 1 отсчёт на символ.
- Разброс — по бутстреп-репликам обучающих файлов, а не по seed обучения.
- Новизну схемы не заявляем: структура известна с 2014 года (Liang, Kumar).
