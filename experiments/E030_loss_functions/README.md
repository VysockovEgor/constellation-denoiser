# E030 — Функция потерь и голова

**Вопрос.** Даёт ли обучение под BER-подобную потерю выигрыш над MSE?

**Правило (до запуска, черновик).** Потеря L лучше MSE, если разность ≥ 0.7 п.п. (5 seeds, интервалы не пересекаются) хотя бы на двух из четырёх моделей. Полностью — `config.json` → `rule_draft`.

**Чем обучалось всё до сих пор** (проверено по коду `runner.run_task`): MSE комплексного символа |y − s|² (для вещественного выхода — MSE по [I, Q]); решение — ближайшая точка созвездия.

**Потери** (`losses_new.py`, тот же выход y, RM не меняется): логиты −β|y − s_k|² по 16 точкам, β = exp(log β) обучается, начальное β = 1 / mean|rx − tx|² по train; `mse`, `ce_dist`, `bit_bce` (биты Грея из `core.BIT_TABLE`), `mse+ce` (+ 0.1·CE). Раннер получил необязательный параметр задачи `loss` (по умолчанию прежний MSE).

**Модели.** one_hidden h48 (F2), v4 h119 (F3), DBP Ns8 (F6), гибрид h48 (F9). S1: 4 потери × 4 модели × lr × {0.5, 1, 2} рецепта × 3 seeds × 60k; S2: лучший lr каждой пары по валидации, 5 seeds × 200k.

**Команда.** `bash experiments/E030_loss_functions/run.sh <стадия>`; стадии: control | s1 | s2 | all | summarize | smoke.

**Результаты.** `results/loss_summary.csv`, `results/loss_verdicts.csv`; рисунок `figures/E030_losses.png`.
