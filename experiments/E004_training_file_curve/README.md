# E004 — Кривая числа train-файлов

## Вопрос
Сравнить качество при росте числа train-файлов на фиксированном holdout.

## Правило интерпретации (до запуска)
`unknown`: в доступных файлах не найдено предварительно записанного правила.

## Протокол
- Размер train набора: N=7, 30, 60, 120, 210.
- Данные и split: `data/manifest/split_E004_learning_curve.json`;
  validation и test — фиксированные группы по 45 файлов.
- Seed: 17 для основной кривой.
- Модели: real/tanh и complex; исторические параметры см. `config.json`.
- Историческая команда: `unknown`.

## Результат
Таблицы в `results/`, график `figures/E004_learning_curve_seed17.png`.
`learning_curve_seed17.csv` содержит complex test BER 0.010160273 при N=7
и 0.003578126 при N=210.

## Вывод
Новая интерпретация задним числом не добавлялась.

## Ограничения
Основная кривая использует один seed и фиксированный ранее выбранный holdout
из 45 test-файлов.
