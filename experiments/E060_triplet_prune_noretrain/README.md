# E060 — Триплеты T (M = 15): обрезка готовых коэффициентов без переобучения

**Вопрос.** Сколько из 368 триплетных членов готовой модели T (T3 + КИХ7, M = 15, закрытая форма) с наименьшими коэффициентами можно обнулить без переобучения, чтобы снижение BER упало не более чем на 0.5 п.п.?

**Правило (до запуска, черновик).** Для каждого способа ранжирования K_val — наименьшее K, при котором снижение на валидации ≥ полного набора − 0.5 п.п.; выбросить можно 368 − K_val членов; test — только для отчёта в точке K_val. Наименьшее K с падением на test ≤ 0.5 п.п. приводится справочно и ни для какого выбора не используется. Один способ лучше другого, только если K_val различаются ≥ 16 членов (два шага сетки). Полностью — `config.json` → `rule_draft`.

**Что делает** (`e060_triplet_prune.py`): коэффициенты E035 `warm_M15.npz` (λ = 1e-4 по валидации, 30 train-файлов); оставляет K членов с наибольшим |C_mn| или |C_mn|·rms(T_mn) на train, остальные C = 0, оставшиеся не меняются, КИХ7 всегда; K = 368, 360, …, 8, 0. Без обучения, без seeds.

**Команда.** `bash experiments/E060_triplet_prune_noretrain/run.sh <стадия>`; стадии: main | smoke.

**Результаты.** `results/prune_curve.csv`, `results/verdict.json`; рисунок `figures/E060_triplet_prune.png`.

## Результат (2026-11-09, сессия E060_1109_1700)

Полный набор (K = 368, RM 4 444): валидация 67.88 %, test 69.27 % (`results/prune_curve.csv`).

| ранжирование | K_val | выброшено | RM при K_val | test при K_val | падение test, п.п. | справочно: K по test |
|---|---|---|---|---|---|---|
| \|C\| | 312 | 56 | 3 772 | 68.87 % | 0.39 | 296 |
| \|C\|·rms(T) | 312 | 56 | 3 772 | 68.87 % | 0.39 | 296 |

Вывод по правилу: без переобучения можно обнулить 56 из 368 членов (−15 % RM). Все 56 внеосевые, большие |m|+|n| (в среднем 23.2 против 13.6 у всего набора). Способы ранжирования не различаются (разница K_val 0 < 16). При K ≤ 48 снижение ниже 30 %, при K = 0 −1 264 %: КИХ7 подогнан вместе с триплетами и без них не работает.

Ограничения: один набор коэффициентов (30 train-файлов), без бутстрэп-реплик и seeds; сетка K с шагом 8; без дообучения оставшихся членов (с дообучением см. E034, E046).
