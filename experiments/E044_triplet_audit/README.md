# E044 — Фаза 0: аудит определений триплетов и ридж-коэффициентов

**Вопрос.** Что именно такое T1, T2, T3 и наборы «K сильнейших», выполняются ли симметрии C_mn = C_nm = C_{−m,−n} = −C*_{−m,n} у ридж-решения, и какая доля |C| приходится на оси (m = 0 или n = 0)?

**Что делает** (`e044_audit.py`, без обучения, на коэффициентах E039): определения из кода; проверка гипотезы «T1/T2 при M = 3 — это 2M + 1 осевых троек»; отклонения от симметрий (медиана и максимум относительной ошибки, |Re C|/|C| на осях); карты |C_mn| в дБ относительно |C₀₀| с границами |mn| = K_th; доли осевых членов по числу и по сумме |C| для полных наборов и набора E038. Равенство C_mn = C_nm проверить нельзя: члены (m, n) и (n, m) в модели объединены.

**Команда.** `PYTHONPATH=src python -m constellation_denoiser.e044_audit` (локально, секунды).

**Результаты.** `results/definitions.csv`, `selection.csv`, `symmetry.csv`, `axis_shares.csv`, `data_facts.json`; рисунки `figures/E044_coef_map_M21.png`, `E044_coef_map_M31.png`.
