# E022 — Базовые методы при равной сложности

**Вопрос.** Превосходит ли наш подход сильные классические базовые методы при равном числе умножений?

**Правило (до запуска, черновик).** Наш подход (лучшая по валидации точка комплексной MLP, Phys + MLP, PhysKerr или DBP в полосе ×1.5 по умножениям) лучше базового, если его Q² выше более чем на 0.1 дБ и интервалы по seeds не пересекаются; обучение нелинейности нужно, если `dbp_train` лучше `dbp_fixed` по тому же порогу. Полностью — `config.json` → `rule_draft`.

**Модели.** Линейный FIR (31–501 отвод, симм./несимм.; окно = длина фильтра, до 2k умножений); DBP с классическим заданным фазовым шагом (R = 1, α из подгонки E015, делится на Ns, не обучается) и его обучаемый двойник; упрощённая вещественная CNN (Re/Im, 3 свёртки, tanh; 2k / 6.3k / 15.8k умножений) — приближение, а не воспроизведение опубликованной сети. 5 seeds, 200k шагов, расписание cosine 3e-3. Ожидается, что заданный DBP почти совпадёт с FIR: в E015 подгонка R = 1 дала α ≈ −0.0019 без выигрыша.

**Команда.** `bash experiments/E022_baselines/run.sh <стадия>`; стадии: probe | plan | estimate | list | control | main | summarize | smoke.

**Результаты.** `results/baselines_summary.csv`, `results/baselines_verdicts.csv`, `figures/E022_baselines_vs_macs.png`; точки E022 входят в график E021.
