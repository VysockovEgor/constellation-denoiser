# E021 — Pareto «качество против сложности»

**Вопрос.** Какое семейство моделей даёт лучшее снижение BER и Q² при заданном числе умножений на символ (уровни ≈2k, 6.5k, 16k, 40k)?

**Правило (до запуска, черновик).** На уровне K берётся лучшая по валидации точка каждого семейства (полоса K/1.5 … 1.5·K); X лучше Y, если разница средних тестов > 1 п.п. и интервалы min–max по seeds не пересекаются, иначе «не различимы». Полностью — `config.json` → `rule_draft`.

**Данные.** Все прогоны E010–E020 с N = 30 (+ E022) и 17 недостающих точек этого эксперимента (200k шагов, 5 seeds). PhysKerr и DBP (≤ 600 умножений) до уровней 2k+ не дотягиваются и показаны в своём диапазоне; точки взяты при разных бюджетах шагов (отмечено в таблице).

**Команда.** `bash experiments/E021_pareto/run.sh <стадия>`; стадии: probe | plan | estimate | list | control | main | summarize | smoke.

**Результаты.** `results/level_best.csv`, `results/level_verdicts.csv`, `results/pareto_points.csv`, `results/pareto_members.json` (участники E023); рисунки `figures/E021_pareto_ber.png`, `figures/E021_pareto_q2.png`.
