# E049 — Физическая инициализация DBP: сверка и проверки без обучения

**Вопрос.** Следуют ли обученные шаги DBP (E018, E025, E028) физическому фильтру дисперсии H(ν) = exp(j c ν²), c = β₂·dz·Rs²/2, dz = 2000 км / Ns, и дают ли физические начальные значения (КИХ, α) выигрыш до обучения?

**Параметры линии.** Rs = 32 Гбод, β₂ = −21 пс²/км, 2000 км: из литературы (Богданов, Сидельников 2021), не проверено на генераторе; c на всю линию −21.5 рад. Сетка: Ns задаётся на всю линию; физическая инициализация КИХ допустима только при Ns ≥ 8 и L = 31 (94 % энергии отклика в окне) или Ns ≥ 16 и L = 15 (93 %); у A1 (один Керр, КИХ7) физического фильтра нет по замыслу.

**Сверка (стадия calib, чекпоинты, без обучения).** c шагов подгоняется по обученным отводам (сетка c, комплексный масштаб, r²). Итог: медиана c на шаг ≈ 0 при всех Ns и L, сумма c по прогону от −5 до +0.9 рад против −21.5; у настроенных моделей r² ≈ 0.4–0.7. Обученные шаги не реализуют пошаговую дисперсию (`results/calib_summary.csv`). Объяснение (гипотеза): дисперсия в данных уже скомпенсирована, а возврат дисперсии всей линии не помещается в окно 31; поэтому физическая инициализация одного знака для этих данных нефизична (в smoke она стартует с −459 %).

**Проверки без обучения.** (1) Ширина ядра α_j по номеру шага (гипотеза: ближе к приёмнику шире; шаг 0 первым применяется к принятому сигналу): связи нет — медиана корреляции Спирмена ширины с номером шага +0.05 (E025, Ns 8, 97 прогонов) и −0.18 (E025, Ns 16, 88 прогонов), в малых группах E018/E028 знак меняется; ширина почти постоянна (≈ 1.8 при R = 7, у равномерного ядра 2.0), то есть |α_j| почти не сосредоточено в центре (`results/alpha_width_summary.csv`). (2) BER на старте при α_j(s) = масштаб · α_total,j / Ns, α_total из осевых коэффициентов ридж-решения M = 15 (α_j = −Im w(0, j)), КИХ = δ; масштаб по минимуму MSE на валидации (знак множителя не фиксирован): минимум при масштабе 0, любой ненулевой масштаб хуже (`results/start_ber.csv`). Пилот на 3 seeds не запускался: на старте выигрыша нет.

**Команда.** `bash experiments/E049_dbp_physical_init/run.sh <стадия>`; стадии: calib | alpha-width | start-ber.
