## Итог разведки

- С сервера пришли результаты E010–E014 (`0d21cbd`, `a29b51d`): все контроли
  прошли допуск (61.63 / 62.19 / 58.76 / 59.44 %). `results/runs/*.json` и
  чекпоинты не забирались: Q² для E010–E014 считается по поштучным CSV
  (`lr_sweep.csv`, `long_runs.csv`, `depth_window.csv`, `transformer_runs.csv`,
  `kan_hybrid.csv`), а остаток модели E014 в E015 не строится.
- `experiments/E010_lr_schedule_study/results/stage3_choice.json`: для `both` и `a`
  лучшая конфигурация — `cosine_to_zero`, пик 3e-3, warmup 0, `c_mult` 30.
- PDF Sidelnikov et al., JLT 2021 нет (в `references/source_papers/` только
  `Bogdanov_341.pdf`, инструментов для чтения PDF тоже нет). Формулы Q² и
  стоимости взяты из промпта без сверки.
- Данные: одна поляризация, 1 отсчёт на символ; созвездие ±1/√10, ±3/√10,
  окружности 0.447 / 1.000 / 1.342. Q² сырого теста ≈ 13.97 дБ.

## Общие решения

- `q2.py`: `q2_db`, `q2_fields`; раннер пишет `q2_db_raw`, `q2_db_model`,
  `q2_gain_db` (финальный тест), те же с префиксами `valbest_select_` и `val_`.
- `phys_models.py`: `PhysStep` (КИХ L + фаза с R коэффициентами, нулевое
  дополнение внутри окна 31), `PhysDBP` (Ns шагов; Ns = 1 — PhysKerr),
  `PhysPlusMLP`. Всё тождественно на старте (проверено).
- `model_zoo.macs_phys(R, L, sym)`; `lr_schedules.is_kerr_coefficient`
  относит `alpha` к группе `c_mult`.

## Решения части 2 (E016)

- КИХ и свёртка мощности — умножение на ленточную матрицу внутри окна
  (`PhysStep._band`), совпадение с `conv1d` проверено; ~5–7× быстрее.
  PhysKerr: 440–545 шагов/с на 1 потоке; DBP из 8 шагов: ~31 шаг/с.
- Smoke нашёл ошибку: в задачах E016 были переставлены R и L. Исправлено,
  добавлена проверка «имя = параметры».
- `estimate` (общий для всех `run.sh`): реальные шаги каждой уникальной модели
  стадии + одна оценка на 1 файле, × коэффициент конкуренции из `resources.json`.
- `control_tasks` принимает `seeds` у контрольного прогона (в E016 `complex_a`
  на 5 seeds, допуск по 17 и 29).
