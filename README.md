# Constellation denoiser

Исследовательский проект по оценке BER и компенсации остаточных искажений 16-QAM сигнала после линейной обработки приёмника.

## Структура

- `data/raw/` — исходные CSV, сохранённые без изменений.
- `references/source_papers/` — статьи и методические материалы.
- `notebooks/` — объяснимые исследовательские блокноты: первичный анализ и визуализация.
- `src/constellation_denoiser/` — повторно используемые функции обработки, метрик, моделей и обучения.
- `reports/results/` — конфигурация эксперимента и таблицы результатов.
- `models/` — веса выбранных обученных прототипов.

Блокноты остаются частью рабочего процесса: они удобны для анализа и представления результата. Повторяющуюся логику и обучение, которое должно запускаться одинаково, держим в `src/` и вызываем из блокнота или команды.

## Запуск

Активировать окружение проекта и выполнить из корня репозитория:

```bash
python -m pip install -e .
python -m constellation_denoiser.experiment --seeds 17 29 43
python -m constellation_denoiser.baselines
```

Если пакет не устанавливался, можно использовать `PYTHONPATH=src`:

```bash
PYTHONPATH=src python -m constellation_denoiser.experiment --seeds 17 29 43
```

Первый скрипт сравнивает MLP, 1D-CNN, двунаправленную LSTM и компактный Transformer. Все модели используют окно из семи принятых символов и предсказывают центральный переданный символ в виде пары I/Q. Обучение минимизирует MSE; BER считается после ближайшей точки 16-QAM. Второй скрипт обучает комплексный линейный FFE на том же split для сопоставления.

## Разбиение для пилотного сравнения

CSV-файлы целиком разделены по реализации PR: PR1–PR7 — обучение, PR8 — выбор эпохи и случайного запуска, PR9–PR10 — пилотный тест. Так соседние перекрывающиеся окна одного файла не оказываются по обе стороны разбиения. Это пилотный протокол; для статьи итоговую оценку нужно подтвердить повторной групповой кросс-валидацией по PR-файлам или новыми реализациями.

## Текущие границы вывода

Пилотное сравнение использует один фиксированный набор архитектур, окно и гиперпараметры. Средние и разброс по трём инициализациям показывают чувствительность к случайным весам, но не заменяют повторение по независимым каналам или наборам данных. Не использовать тест PR9–PR10 для дальнейшего подбора архитектуры, если эти же результаты будут называться финальной оценкой.
