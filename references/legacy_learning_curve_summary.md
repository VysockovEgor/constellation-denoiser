# Кривая обучения на фиксированном тесте

## Протокол

- Во всех точках использовались одни и те же 45 test-файлов и одни и те же 45 validation-файлов из масштабного пилота.
- Обучающие наборы вложенные: 7, 30, 60, 120 и 210 файлов, выбранные из фиксированного пула из 210 train-файлов с seed порядка подвыборки `20261004`.
- Сравнивались вещественная MLP с `tanh` (2 слоя по 64 нейрона) и комплексная MLP с фазовой активацией статьи (2 слоя по 32 комплексных нейрона).
- Обе сети: окно 31 символ, Adam, MSE, batch size 1024, learning rate 0.001, максимум 40 эпох; лучший checkpoint выбирался по validation BER, затем по validation MSE.
- Для кривой использован один и тот же seed инициализации модели: `17`. Комплексная сеть на 7 файлах дополнительно была доведена до 40 эпох; для всех остальных точек фактическое число эпох также составило 40.
- Сравнивается средний BER по отдельным тестовым файлам. Raw BER на том же тесте: **0.009552**.

## Вывод и ограничения

На этом фиксированном наборе тестовых файлов увеличение обучающего набора совпало с ростом выигрыша комплексной сети: от отсутствия выигрыша на 7 файлах до 62.5% на 210. Tanh MLP также перешла от нулевого выигрыша к примерно 30%. Это поддерживает объяснение, что малой выборки было недостаточно для устойчивого обучения; гипотеза об утечке через повторяющиеся переданные фрагменты с этим результатом не согласуется.

Это предварительная кривая, а не публикационное доказательство: по всем размерам приведён один seed, использован один фиксированный split, а эти 45 тестовых файлов ранее уже оценивались в масштабном пилоте. Поэтому график показывает поведение моделей на данном holdout, но его нельзя трактовать как независимую финальную оценку. Для статьи нужно повторить кривую по нескольким seed/разбиениям и выделить новый незатронутый тестовый набор.

Полные строки запусков, включая дополнительные seed ранних размеров, хранятся в `learning_curve_runs.csv`; однородная таблица seed 17 — `learning_curve_seed17.csv`; все метрики по файлам — `learning_curve_per_file.csv`; параметры разбиения — `learning_curve_config.json`.
