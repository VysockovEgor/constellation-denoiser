# Литература и исходная постановка

- `source_papers/Bogdanov_341.pdf` — статья Богданова и Сидельникова о комплексной полносвязной сети для компенсации нелинейных искажений в волоконно-оптической линии.

Статья используется как научный ориентир, а не как гарантия результата на предоставленных PR-файлах.

`references.csv` — список литературы, на которую опираются эксперименты: что прочитано (полный текст, аннотация, пересказ), для чего используется, известные параметры. Неизвестные поля помечены `unknown`.
