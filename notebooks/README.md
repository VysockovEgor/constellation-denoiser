# Jupyter notebooks

Блокноты оставлены как исследовательские документы: они фиксируют ход анализа, графики и выводы. Повторно используемые функции импортируются из `src/constellation_denoiser`, чтобы исправления не приходилось копировать между блокнотами.

- `01`–`05` — первоначальный разбор и эксперименты на PR1.
- `06_model_comparison.ipynb` — просмотр результата группового сравнения четырёх оконных моделей.

Их можно открывать из корня проекта или из этой папки; ноутбуки добавляют `src/` в путь импорта.
