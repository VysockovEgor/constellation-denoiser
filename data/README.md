# Данные

CSV-файлы перемещены в `raw/` без изменения содержимого. Каждая строка содержит `tx_I, tx_Q, rx_I, rx_Q` для одного символа. В репозитории ожидаются PR1–PR10; прежняя копия PR6 удалена владельцем проекта и не должна учитываться повторно.

Имя файлов содержит `1m`, но фактическая длина каждой предоставленной последовательности — 16 384 символа. PR-последовательности используются как групповые единицы разбиения; независимость их генерации следует подтвердить по описанию набора у научного руководителя.
