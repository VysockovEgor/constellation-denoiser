# Checkpoints

По одному checkpoint на архитектуру сохранено из трёх обучений. Выбор сделан по BER на validation PR8 (при равном BER — по MSE), без использования тестовых BER. Модели обучены на PR1–PR7, окно 7, CPU.

Каждый `.pt` содержит архитектуру, окно, seed, веса и списки файлов split. Форматы всех весов соответствуют классам в `src/constellation_denoiser/models.py`.

`complex_ffe.npz` содержит 8 комплексных коэффициентов (7 линейных отводов и bias), обученных на PR1–PR7.
