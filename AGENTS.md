# Правила работы с экспериментами

- Каждый новый эксперимент создаётся в новой папке `experiments/E00N_название/`.
- До запуска в README эксперимента записываются вопрос и правило интерпретации.
- В `config.json` записываются все параметры, seed, git-коммит и SHA-256 манифеста
  данных. Для неизвестных исторических параметров указывать `unknown`, не угадывать.
- Не использовать test для выбора checkpoint.
- Старые результаты и checkpoint не перезаписывать. Новый запуск требует нового
  E-номера и нового пути для результатов и весов.
- После запуска дописывать запись в конец корневого `LOG.md`; существующие записи
  не редактировать.
- Не называть утверждение выводом без численного результата и ссылки на файл.
- В каждой записи указывать ограничения, число seed, файлов и шагов.
- `data/raw/` — только чтение. Дубли данных не удалять без одобрения владельца.
- Данные и checkpoint не добавлять в Git. Проверять staging, а не только
  `.gitignore`.
- Графики именовать `E00N_<название>.png`; порядок презентации задаёт
  `paper/figures_manifest.csv`, а не имя файла.
