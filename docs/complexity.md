# Сложность: вещественные умножения на символ (RM)

В таблицах результатов колонки называются `macs_per_symbol` (как обучалось) и `macs_per_symbol_merged` (после слияния линейных слоёв без активации между ними). В новых страницах величина называется «RM/символ», имена колонок не меняются. Проверка всех таблиц E010–E023 — `experiments/E024_data_audit/results/rm_audit*.csv` (`rm_audit.py`, независимые формулы).

## Конвенция

| операция | RM |
|---|---|
| комплексное умножение | 4 |
| вещественное × комплексное | 2 |
| \|z\|² | 2 |
| Kerr-активация exp(i·c·\|z\|²)·z на нейрон | 7 (\|z\|² 2 + c·\|z\|² 1 + поворот 4; exp, cos, sin — из таблицы) |
| вещественные активации (tanh, ReLU, GELU, SiLU), сложения, смещения, LayerNorm, softmax | 0 |
| деление | 1 (только в активациях E027) |

Колонки новых прогонов: `rm_total` = `macs_per_symbol` (всё, что выполняется на символ), `rm_linear` = доля линейных слоёв (4·вход·выход у комплексных, вход·выход у вещественных); для MLP `rm_linear = rm_total − RM_act·h`.

## Формулы

- Kerr MLP, два скрытых слоя (`complex_both`): 4h(W + h + 1) + 14h (W = 31, h = 48: 16 032).
- Один скрытый слой (`complex_one_hidden`; `complex_a` после слияния): h(4W + 11) (h = 48: 6 480; h = 119: 16 065).
- `complex_a` как обучается: 4Wh + 4h² + 4h + 7h (15 696).
- Вещественный MLP: 2Wh (+ h² при двух слоях) + 2h (62-96-96-2: 15 360; один слой h = 100: 6 400).
- Физика (`model_zoo.macs_phys`): шаг DBP = КИХ (2(L + 1) при симметрии, 4L без неё) + 2 + R' + 4, R' = (R + 1)/2 при симметрии; Ns шагов — умножить на Ns (R31 L7 sym: 38; Ns8 L31 R7: 592). Гибрид: + h(4W + 11).
- Активации E027: 4Wh + 4h + RM_act·h, RM_act: kerr 7, taylor1 8, modReLU 5, cardioid 6, sigmoid-gate 5, CReLU/split-tanh/identity 0.
- Триплеты E031: `naive` 12 на упорядоченный триплет (два комплексных умножения + коэффициент), `sym` 12 на объединённый член (C_{m,n} = C_{n,m}); + 4L у КИХ.
- Трансформер: вход 2dW, слой W(4d² + 2·ffn·d²) + 2W²d, голова d² + 2d (без переиспользования между окнами); KAN — разреженная оценка `kan.kan_model_cost`; CNN — Σ C_in·C_out·k.

## Сверка со статьёй научного руководителя

`references/source_papers/Bogdanov_341.pdf` (Богданов, Сидельников, «Квантовая электроника» 51, 2021) считает вещественные умножения линейных слоёв: «одно комплексное умножение требует четырёх операций умножения вещественных чисел», и сравнивает комплексную сеть 32 нейрона на слой с вещественной 64 нейрона при одинаковой сложности. При W = 21 обе дают 6 912 умножений только линейных слоёв: 4(32·21 + 32² + 32) = 2·21·64 + 64² + 2·64. Различие: мы добавляем 7 RM на Kerr-нейрон (в статье стоимость активации не учитывается), поэтому наши числа для Kerr-сетей больше на 7h на слой (для h = 48 и одного слоя — 336 из 6 480, ≈ 5 %). В JLT 2021 (Сидельников и соавт.) нелинейный шаг DBP оценён как 0.25(R + 1) + 6; у нас 0.5(R + 1) + 6, вероятная причина — две поляризации в статье (одна свёртка мощности на обе); PDF JLT в репозитории нет, не сверялось.
